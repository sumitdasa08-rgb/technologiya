🔐 ENVIRONMENT VARIABLES

Required credentials (update in .env.local):

📱 Telegram:
   TELEGRAM_BOT_TOKEN=your_bot_token_here
   TELEGRAM_CHAT_ID=your_chat_id_here
   TELEGRAM_WEBHOOK_SECRET=generate_random_secret

📧 Email (Brevo):
   BREVO_API_KEY=your_api_key_here
   SENDER_EMAIL=your_verified_email@domain.com

💳 Payment:
   UPI_ID=your_upi_id@bank

How to get these:
• Telegram: Talk to @BotFather, create a new bot
• Brevo: Get from https://app.brevo.com/settings/keys/api
• Webhook Secret: openssl rand -hex 16

🧠 UNDERSTANDING THE FLOW

User Interaction:
1. User fills booking form on frontend
2. Frontend validates input
3. Frontend calls /create-booking API
4. Backend creates booking, returns confirmation
5. Backend sends Telegram notification (background)
6. User gets booking reference (e.g., ABC123XY)

Status Update:
7. Admin receives Telegram message with payment buttons
8. Admin clicks "✅ Payment Received"
9. Telegram sends webhook callback
10. Backend updates booking status
11. Backend sends email confirmation
12. Customer receives email

Tracking:
13. Customer goes to /track page
14. Enters booking reference
15. Sees repair status and progress

🆘 COMMON ISSUES & QUICK FIXES

Issue: "Port 5173 already in use"
Fix:   npm run dev -- --port 3000

Issue: "Supabase command not found"
Fix:   npm install -g supabase

Issue: "Telegram messages not sending"
Fix:   Check TELEGRAM_BOT_TOKEN and TELEGRAM_CHAT_ID in .env.local

Issue: "Emails not received"
Fix:   Verify BREVO_API_KEY and SENDER_EMAIL are correct

Issue: "Database empty"
Fix:   Run migrations (see LOCAL_SETUP.md Part 2)

Issue: "Tests show red errors"
Fix:   Run: node test-webhooks.js for detailed diagnosis

For more help → See DEBUGGING.md
